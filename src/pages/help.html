Começando

Para criar uma conta no VClass:

  1. Clique em "Registar" no menu superior
  2. Preencha seus dados pessoais (nome, email, senha)
  3. Selecione seu país e nível de ensino
  4. Escolha se é estudante ou professor
  5. Clique em "Criar Conta"
  6. Verifique seu email para ativar a conta

A navegação é hierárquica:

  • Disciplinas: Escolha a matéria que quer estudar
  • Capítulos: Selecione o tópico específico
  • Aulas: Assista vídeos e faça exercícios
  • Use a barra de busca para encontrar conteúdo específico

Sim, mas com limitações:

  • App Mobile: Baixe aulas para assistir offline
  • Web: Requer conexão para streaming de vídeo
  • PDFs: Podem ser baixados para leitura offline
  • Seu progresso é sincronizado quando voltar online

Player de Vídeo

O player ajusta automaticamente, mas você pode:

  1. Clique no ícone de engrenagem (⚙️) no player
  2. Selecione "Qualidade"
  3. Escolha: Auto, 240p, 360p, 480p ou 720p
  4. Qualidades mais baixas usam menos dados

Download depende do tipo de conta:

  • Conta Gratuita: Apenas streaming online
  • Premium: Download no app mobile (criptografado)
  • Vídeos baixados só funcionam dentro do app
  • Download direto não é permitido por segurança

Para ativar legendas:

  1. Clique no ícone de legendas (CC) no player
  2. Selecione o idioma disponível
  3. Ajuste tamanho e cor nas configurações
  4. Legendas estão disponíveis em português

Exercícios e Avaliações

Para fazer exercícios:

  1. Assista a aula completa primeiro
  2. Role até a seção de exercícios
  3. Leia cada questão com atenção
  4. Selecione sua resposta
  5. Clique em "Submeter" para ver o resultado
  6. Veja explicações das respostas corretas

Acompanhe seu progresso em:

  • Dashboard: Visão geral de todas as disciplinas
  • Página de Progresso: Detalhes por matéria
  • Gráficos: Visualize seu desenvolvimento
  • Histórico: Veja todas as atividades completadas

Sim, você pode:

  • Refazer qualquer exercício quantas vezes quiser
  • Cada tentativa gera questões aleatórias diferentes
  • Sua melhor pontuação é salva
  • Use para estudar e melhorar sua nota

Problemas Técnicos

Soluções comuns:

  1. Verifique sua conexão de internet
  2. Reduza a qualidade do vídeo para 240p ou 360p
  3. Limpe o cache do navegador
  4. Tente outro navegador (Chrome, Firefox, Safari)
  5. Desative extensões do navegador temporariamente
  6. Reinicie seu dispositivo

Para recuperar sua senha:

  1. Clique em "Esqueceu a senha?" na tela de login
  2. Digite seu email cadastrado
  3. Verifique sua caixa de entrada (e spam)
  4. Clique no link de recuperação
  5. Crie uma nova senha segura
  6. Faça login com a nova senha
