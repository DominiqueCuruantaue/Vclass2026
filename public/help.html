Começando
  1. Clique em Criar Conta no menu
  2. Preencha nome, email e senha
  3. Selecione seu tipo de conta (Estudante ou Professor)
  4. Aceite os termos e clique em "Criar Conta"
  5. Faça login e comece a estudar!

A navegação é hierárquica:

  • País → Série → Disciplina → Capítulos → Aulas
  • Acesse via menu Conteúdo na navbar
  • Use a busca para encontrar conteúdo específico
  • Vídeos requerem conexão (streaming)
  • PDFs podem ser baixados para leitura offline
  • Progresso é sincronizado quando voltar online
Player de Vídeo
  1. Clique no ícone ⚙️ no player
  2. Selecione "Qualidade"
  3. Escolha: Auto, 240p, 360p, 480p ou 720p
  4. Qualidades mais baixas usam menos dados

Atualmente o download está disponível apenas via app mobile (em breve). Na versão web, os vídeos são transmitidos por streaming.

Clique no botão CC no player. As legendas estão disponíveis em Português para a maioria das aulas.

Exercícios e Avaliações
  1. Assista a aula completa
  2. Role até a seção de exercícios (ou clique em "Exercícios")
  3. Leia cada questão e selecione sua resposta
  4. Clique em "Submeter" para ver o resultado e a explicação
  • Acesse Progresso no menu
  • Veja gráficos e detalhes por disciplina
  • O Dashboard mostra um resumo geral

Problemas Técnicos
  1. Verifique sua conexão de internet
  2. Reduza a qualidade do vídeo para 240p
  3. Limpe o cache do navegador (Ctrl+Shift+R)
  4. Tente outro navegador (Chrome recomendado)
  5. Desative extensões que podem interferir
